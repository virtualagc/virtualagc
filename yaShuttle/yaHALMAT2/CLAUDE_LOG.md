Confirmed via real compiled HALMAT: `HALMAT #60 IASN` with operand 2 = Symbol AB (VECTOR). Previously fatal: `write_destination`'s whole-array QUAL_SYT branch unconditionally required `arrayed_index >= 0`. Fixed per [USA003087] Sec. 8.2 rule 3 (MATRIX)/rule 3 (VECTOR): literal INTEGER 0 assigned to a whole MATRIX/VECTOR receiver "creates a null matrix"/"creates a null vector" (zeros every element) — any other value is illegal HAL/S and never expected to reach the interpreter. New `syt_is_vector_or_matrix_shaped()` helper (excludes ARRAY, which has no documented equivalent) gates a zero-fill loop in `write_destination` (interp.c) before the existing arrayed-paragraph-replay fail path. Regression fixture: `src/tests/hal/test_vecmat_null_assign.hal`, wired into `run_all.sh`; confirmed to fail on pre-fix code with the exact user-reported error, and confirmed against a real `039-CORNERS.hal` run with the user's reported input (`1 2,0.2`).
