
### [2026-09-16] Target: HANDOFF-panelO6.md, README.md
- Crew scripts may call scripts: `script FILE` plays FILE here and carries on afterwards, the caller's remaining times counting from when FILE finished (as after a wait). The whole tree is read and checked when the first script is read (entry["entries"]), a relative FILE is relative to the script naming it, self-calls and nesting over MAX_SCRIPT_DEPTH 8 are refused, and crewscript.count_entries/needs_user walk the tree. crewscript.parse takes the file path now; panelO6, simulatePASS and the checker pass it.
- panelO6 listens for script commands on port base + 92 (crewscript.CONTROL_OFFSET, send_control/control_receiver): "play FILE" (read and checked in the listener thread, then handed to Tk) and "stop". The panel keeps its player as panel.player, so a new script replaces the one playing. The channel is open whether or not --script was given.
- New manager.py: a Tk control window -- script Play/Stop (through that channel), layout Save/Restore (windowLayout.save_layout/restore_layout), caption box Start/Stop (with the look from the layout file), and a status line listing this simulation's programs found by --port-base in /proc (wrappers such as timeout skipped; the program is the first argv entry whose basename is one of ours, so python3 -u X.py works). No emulator pause: yaGPC2 has none and SIGSTOP leaves the displays timing out. simulatePASS starts one by default; --no-manager suppresses it.
